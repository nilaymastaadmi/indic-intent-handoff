# Routing a request in 6 languages, and knowing when to hand it to a person

A support assistant has two jobs before it answers anything: route the request to the right intent in
the customer's language, and hand off to a person when the request is something it was never trained
on. This study measures both, in English and 5 Indian languages (Hindi, Tamil, Telugu, Kannada,
Malayalam), with a small multilingual encoder fine-tuned by LoRA on a laptop CPU.

Everything was **pre-registered before any model code existed** (`PREREGISTRATION.md`, with the six
held-out intents drawn by a fixed seed); every later change is in `AMENDMENTS.md` with its reason. The
test split is sealed in code and was opened once (`results/UNSEAL.log`). Results are generated by a
script, never typed: see `results/RESULTS.md`. Phase-1 research, published baselines with page
references and the compute budget: `RESEARCH.md`.

## Pipeline

| Stage | Choice | Why |
|---|---|---|
| Data | MASSIVE 1.1 (FitzGerald et al., ACL 2023; CC-BY-4.0): en-US, hi-IN, ta-IN, te-IN, kn-IN, ml-IN, 16,521 utterances each, parallel by id | The only public intent set found with 5 Indian languages; parallel ids make every cross-language comparison paired |
| Known vs unknown | 6 of 60 intents held out by `random.Random(20260924)` before any code: 54 known intents; 10,262 / 1,835 / 2,679 known train / dev / test and 295 unknown test utterances per language | Unknowns are near-domain (`alarm_query` next to the known `alarm_set`), the realistic hand-off case |
| Encoder | `intfloat/multilingual-e5-small`, 117.7M parameters, revision pinned | 0.65 to 0.75 s per training step on this CPU (measured); larger encoders did not fit the budget |
| A0 | Majority known intent | Floor |
| A1 | Character 2-5-gram TF-IDF + logistic regression | Strong no-neural baseline |
| A2 | Frozen e5-small, mean-pooled + logistic regression | What LoRA must beat |
| A3 | e5-small + LoRA r = 8, alpha 16 on query and value in all 12 layers + linear head: 168,246 trainable parameters (0.143%), 3 seeds | Parameter-efficient fine-tuning |
| Regimes | EN-only (zero-shot to 5 Indian languages) and JOINT (all 6) | How much zero-shot costs, and how much real target-language data recovers |
| Hand-off scores | Max-softmax (Hendrycks and Gimpel 2017) and Mahalanobis distance with a shared covariance (Lee et al. 2018; Podolskiy et al. 2021) | The standard baseline and one stronger score that needs no unknown examples |
| Threshold | Set on English dev to keep 95% of known requests, applied unchanged to every language | The deployable version of the hand-off, not only the threshold-free AUROC |
| Uncertainty | 2,000-resample bootstrap over test ids, shared across arms and languages (paired); 3 seeds for A3 with the range printed | Two separate sources of spread |

## Results (every number from `results/RESULTS.md`)

**Void check first.** V1, the pipeline check against the model card, **failed**: 64.4% against 70.3 +/- 2.0.
Under the pre-registration the frozen-embedding arm A2 is therefore void; its numbers are printed in
`RESULTS.md` labelled VOID and nothing here is concluded from them (amendment A4). V2 to V4 passed.

Known-intent test accuracy, 2,679 utterances per language (A3 = mean of 3 seeds; 95% bootstrap CIs and seed
ranges in `RESULTS.md`):

| Arm | Regime | en-US | hi-IN | ta-IN | te-IN | kn-IN | ml-IN |
|---|---|---|---|---|---|---|---|
| A0 majority | either | 7.8 | 7.8 | 7.8 | 7.8 | 7.8 | 7.8 |
| A1 char TF-IDF + LR | EN-only | 84.0 | 9.7 | 6.8 | 7.9 | 7.8 | 7.7 |
| A1 char TF-IDF + LR | JOINT | 83.7 | 82.9 | 81.9 | 81.8 | 80.8 | 83.1 |
| **A3 LoRA** | EN-only | **86.4** | 71.4 | 58.7 | 59.7 | 58.8 | 67.8 |
| **A3 LoRA** | JOINT | **87.0** | **84.1** | **80.9** | **81.6** | **81.6** | **83.5** |

- **Zero-shot costs 15 to 28 points** (English minus each language, EN-only LoRA): Hindi 15.0, Malayalam
  18.5, Telugu 26.7, Kannada 27.6, Tamil 27.7. Hindi has the smallest gap, as predicted.
- **Joint training closes 83% of that gap** (80% to 85% per language).
- **A character n-gram baseline is close once it sees each language**: JOINT TF-IDF is within 1.2 points of
  JOINT LoRA on each of the 5 Indian languages, in both directions (descriptive; no paired test was pre-registered for A1 vs A3).
  Trained on English only it is at the majority-class floor, because the scripts share no characters.
- **Hand-off to a person on the 6 unseen intents (A3, max-softmax):** AUROC 0.792 in English and 0.611 to
  0.702 in the Indian languages when trained on English only; 0.818 and 0.754 to 0.774 when trained jointly.
  A threshold set on English dev to keep 95% of known requests kept 94.7% in English but only 76.3% to 84.5% in
  the Indian languages (EN-only model), and 90.5% to 93.3% (JOINT model). At that threshold the EN-only model
  catches only 20.6% of unseen English requests: an AUROC near 0.8 is far from a usable hand-off on its own.
- **Mahalanobis distance did not beat max-softmax**: +0.002 AUROC in English (EN-only), and below it
  under JOINT (0.748 vs 0.818). An exploratory dev-split probe (`iih/explore_maha.py`) found distance scores
  on frozen vectors near chance for these near-domain unknowns.

**What V1 should have been.** It fed the study's L2-normalised embeddings to MTEB's fixed C = 1 classifier.
On the dev split the same protocol gives 65.6% normalised and 71.5% raw (`iih/explore_v1.py`,
exploratory), so the check measured a preprocessing choice, not a broken pipeline. It could have been run on
dev before training; the void stands because the rule was fixed in advance.

## Limitations

- **MASSIVE is voice-assistant commands, not support tickets.** The study measures multilingual routing and
  hand-off mechanics; the numbers will not carry over to longer, noisier, multi-intent support text.
- One small encoder (e5-small). Published zero-shot means for Indic-trained encoders (MuRIL 77.6, IndicBERT
  v2 79.1) are well above this model's 63.3; they did not fit the CPU budget (`RESEARCH.md`).
- The chosen learning rate, 1e-3, is the top of the pre-registered grid and dev accuracy was still rising
  (53.0%, 77.5%, 86.6%); a higher rate might do better. Final-epoch checkpoints, no early stopping.
- The 6 unknown intents are one seeded draw; a different draw would move the hand-off numbers.
- The test split was opened by one pass, but `UNSEAL.log` has 4 lines: the pass was interrupted and resumed
  (amendment A3), and a relaunch helper named like a test file was imported twice by pytest, re-running the
  stage with every output already present (amendment A5). No prediction file changed (`results/preds.sha1`).

## Reproduce

```
uv venv .venv --python 3.13
uv pip install torch==2.14.0 --index-url https://download.pytorch.org/whl/cpu
uv pip install transformers==5.17.0 peft==0.21.0 scikit-learn==1.9.0 numpy==2.5.3 pytest
# data: MASSIVE 1.1 tarball (40,251,390 bytes) unpacked to data/1.1/ (see RESEARCH.md section 1)
python -m pytest -q            # 8 tests, each shown failing on a planted defect before it counted
python -m iih.run embed        # frozen embeddings, about 16 min on a 16-thread laptop CPU
python -m iih.run tune         # C for A1 and A2, learning rate for A3, English dev only, about 70 min
python -m iih.run train        # A3: 2 more EN-only seeds (20 min each), 3 JOINT seeds (65 min each)
python -m iih.run test         # the single sealed pass + the V1 pipeline check
python -m iih.analyse          # writes results/RESULTS.md
python -m iih.alignment        # exploratory: translation alignment in frozen e5 space, dev only
python -m iih.explore_v1       # exploratory: why V1 failed, dev only
python -m iih.explore_maha     # exploratory: distance scores on frozen vectors, dev only
```

Machine: Intel i7-1360P (16 threads), 15.7 GB RAM, no GPU, Windows 11, Python 3.13.5. CPU load and
clock were recorded before each stage (`results/run.log`), and every run held the machine awake.

Built with AI assistance (Claude Code); design and every number reproducible from this repository.
